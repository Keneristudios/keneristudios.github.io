The Keneri standards

How we build.

Four rules that decide what ships and what does not.

Privacy is architecture, not a promise

No accounts where none are needed. Data stays on the device. AdMob is the only ad network, and never a data broker.

Depth over dopamine

Real economic models, real syllabi, real work. We would rather a product be used for an hour a week than clicked for a minute a day.

Offline is the default

Core features work with no connection. Anything that needs the network says so before it uses it.

No dark patterns

No fake urgency, no invented limits, no countdowns that restart. If a limit exists, it is real and it is explained.

Under the hood

Built close to the metal.

Native where performance matters, cross-platform where reach does.
